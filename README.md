# Career Guidance

An interactive web application that helps students explore suitable career paths based on their interests and skills.

## Features

- Career exploration
- Interest and skill assessment
- Career recommendations
- Career-related information

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Run Locally

1. Open a terminal in the frontend folder.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in the terminal.
